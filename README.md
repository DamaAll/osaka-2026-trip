# Osaka 2026 Trip

Mobile-first travel execution site for Osaka, Kyoto and Universal Studios Japan.

- Travel dates: 2026-09-21 to 2026-09-25
- Entry point: `index.html`
- Static site; no build step required
- Designed for GitHub Pages

The itinerary focuses on practical on-trip use: station names, lines, directions, fares, Google Maps links and a persistent pre-trip checklist.
