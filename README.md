# Osaka 2026 Trip

Mobile-first travel execution site for Osaka, Kyoto and Universal Studios Japan.

- Travel dates: 2026-09-21 to 2026-09-25
- Stack: Vue 3 + Vite
- Entry point: `src/main.js`
- Production build: `npm run build`
- Mobile verification: `npm run test:mobile`
- Deployed through GitHub Pages

The itinerary focuses on practical on-trip use: station names, lines, directions, fares, Google Maps links, decision cutoffs, weather fallbacks and a persistent pre-trip checklist.
